# Two-Card Pipeline Inference Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run one model across two FK33 cards with the host carrying the residual between them, proven token-for-token on the 9B against the single-card card, so that the 27B can then be split by layer.

**Architecture:** Layer split (card 0 = blocks 0..N, card 1 = the rest plus the LM head). The residual leaves card 0 through the seam's existing window 3 plus one NEW read-only register carrying its block exponent, and enters card 1 through window 2 plus `X_EXP`, exactly as the embedding does today. A thin `pl_pipeline` layer over two `pl_ctx` owns the per-position loop. Per-card images come from the packer's `--drop`; per-card programs from the generator's new block range.

**Tech Stack:** VHDL-2008 under GHDL mcode (`sim/regress.sh`), Python 3 tools, C11 host code (`server/`), Vivado 2023.2 for the one card build, `fk33_chat.sh` on silicon (human only).

**Spec:** `docs/superpowers/specs/2026-09-21-two-card-pipeline-design.md`

## Global Constraints

- No hardware access from any subagent, ever: no `xsdma`, `fk33_reload.sh`, `fk33_chat*.sh`, `fk33ctl.py` against `/dev/xdma*`, `run_prompt --allow-hardware`. Tasks marked HUMAN are run by Oren or the main session only.
- Generated files carry a banner on line 2; edit the generator, regenerate, `git diff` the output. `rtl/fk33_llama_top.vhd` is generated by `tools/gen_cardtop.py` FROM `rtl/llama_top.vhd`; `hw/fk33/rtl/fk33_card.vhd` by `hw/fk33/gen_fk33_card.py` (via `tools/gen_bd_wrapper.py`) from `fk33_llama_top`; `hw/fk33/build_fk33_pcieep.tcl` by `hw/fk33/gen_pcieep.py` and must be regenerated with its GENSTAMP values.
- `sim/regress.sh --only <substring>`; read the ` OVERALL PASS n` line, never the `REGRESSION:` word alone. Never edit `sim/regress.sh` while a gate is live.
- Every new bench check counts in a VARIABLE, never a signal. Every new check gets a mutant that it kills AND an attribution control (the mutant with the new check disabled).
- Commits: explicit paths only, message via `git commit -F <file>`, no Co-Authored-By, no emojis, no em-dashes.
- Scratch under `/mnt/storage/fk33_builds/scratch/<track>/`, never `/tmp`.
- Widths: `EXP_W = 16` in `llama_top`, `fk33_seam` and on the card (`smp_exp : signed(15 downto 0)`); the new exponent port is `signed(15 downto 0)` everywhere.
- Register offsets are literal on both sides and cross-checked: `rtl/fk33_seam.vhd` `A_*` constants, `server/fk33_seam.h` `FK33_SEAM_*`, `hw/fk33/host/fk33ctl.py` `SEAM_*`. The new register is at `0xA4`, the next free offset after `A_KV_MAXPOS = 0xA0`. The new capability bit is bit 6.

```c
int pl_read_xout(pl_ctx *c, int16_t *mant, int32_t *exp)
{
    uint32_t v = 0; int i;
    if (!c || !mant || !exp) return -1;
    if (!(c->caps & FK33_CAP_XEXP_OUT)) return -1;   /* c->caps: the flags read at open */
    if (wr(c, FK33_SEAM_WIN_SEL, FK33_WIN_XOUT)) return -2;
    if (wr(c, FK33_SEAM_WIN_ADDR, 0)) return -2;
    for (i = 0; i < c->n_embd; i++) {
        if (rd(c, FK33_SEAM_WIN_DATA, &v)) return -2;
        mant[i] = (int16_t)(uint16_t)v;
    }
    if (rd(c, FK33_SEAM_XEXP_OUT, &v)) return -2;
    *exp = (int32_t)v;
    c->from_card += (uint64_t)c->n_embd * 4u;
    return 0;
}

static int push_row(pl_ctx *c, const int16_t *row, int32_t exp)
{
    int i;
    if (c->version < 2) return -1;
    if (wr(c, FK33_SEAM_X_EXP, (uint32_t)exp)) return -2;
    if (wr(c, FK33_SEAM_WIN_SEL, FK33_WIN_XIN)) return -2;
    if (wr(c, FK33_SEAM_WIN_ADDR, 0)) return -2;
    for (i = 0; i < c->n_embd; i++)

/* server/pl_pipeline.c -- two cards, one model, the host carries R_X. */
#include "pl_pipeline.h"
#include <stdlib.h>
#include <string.h>
#include <time.h>

struct plp_ctx {
    pl_ctx *c0, *c1;
    int n_embd;
    int16_t *row;      /* n_embd, the hop buffer */
};
static double g_read = 0, g_write = 0; static unsigned long g_hops = 0;
static double now_s(void){ struct timespec t; clock_gettime(CLOCK_MONOTONIC,&t); return t.tv_sec + t.tv_nsec*1e-9; }

int plp_open(pl_ctx *c0, pl_ctx *c1, plp_ctx **out)
{
    plp_ctx *p;
    if (!c0 || !c1 || !out) return -1;
    if (pl_n_embd(c0) != pl_n_embd(c1)) return -1;
    p = (plp_ctx *)calloc(1, sizeof *p);
    if (!p) return -1;
    p->c0 = c0; p->c1 = c1; p->n_embd = pl_n_embd(c0);
    p->row = (int16_t *)calloc((size_t)p->n_embd, 2);
    if (!p->row) { free(p); return -1; }
    *out = p; return 0;
}
void plp_close(plp_ctx *p){ if (p){ free(p->row); free(p); } }
int plp_seq_reset(plp_ctx *p){ int r = pl_seq_reset(p->c0); return r ? r : pl_seq_reset(p->c1); }
int plp_seq_pos(const plp_ctx *p){ return pl_seq_pos(p->c1); }

/* One hop: card 0 has completed position pos; carry R_X into card 1 and run it. */
static int hop_and_run1(plp_ctx *p, int *argmax)
{
    int32_t e = 0; int rc; double t0 = now_s(), t1;
    rc = pl_read_xout(p->c0, p->row, &e);
    if (rc) return rc;
    t1 = now_s(); g_read += t1 - t0;
    rc = pl_decode_row(p->c1, p->row, e, NULL, NULL, argmax);
    g_write += now_s() - t1; g_hops++;
    return rc;
}

int plp_prefill(plp_ctx *p, const int *ids, int n, int *argmax)
{
    /* OVERLAP: card 0 runs position k+1 while card 1 runs position k.  The
     * order is: c0(k) ; then for k in 0..n-2: read xout(k), issue c1(k) AND
     * c0(k+1), wait both; then hop the last.  pl_decode is blocking, so the
     * overlap here is achieved by issuing c0(k+1) BEFORE waiting on c1(k):
     * pl_decode_row on c1 blocks, so we issue c0 first via pl_decode (blocking
     * too).  Phase 0 keeps it SERIAL and measurable; the overlap lands in
     * Task 10 once pl_go_async/pl_wait exist.  Recorded here so nobody reads
     * this loop as the final shape. */
    int k, rc, am = -1;
    if (!p || !ids || n <= 0) return -1;
    for (k = 0; k < n; k++) {
        rc = pl_decode(p->c0, ids[k], NULL, NULL, &am);   /* argmax of card 0 is meaningless (no LM head) */
        if (rc < 0) return rc;
        rc = hop_and_run1(p, argmax);
        if (rc < 0) return rc;
    }
    return n;
}

int plp_decode(plp_ctx *p, int id, int *argmax)
{
    int rc, am = -1;
    rc = pl_decode(p->c0, id, NULL, NULL, &am);
    if (rc < 0) return rc;
    return hop_and_run1(p, argmax);
}
void plp_hop_timing(double *r, double *w, unsigned long *h){ if(r)*r=g_read; if(w)*w=g_write; if(h)*h=g_hops; }
```
Note the card-0 `pl_decode` is used for the embedding push and GO; its argmax is ignored because card 0's program has no LM head.
